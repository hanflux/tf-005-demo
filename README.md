# 收拾就完了 · 评审试玩版

原创单关分类收纳网页小游戏。先看上方分类再拿物品，未开放分类进入3格暂存，第4件会失败；收满分类后换箱并自动处理匹配暂存。被压住的物品先移上层。

声音在首次点击或键盘手势后开启。音乐/音效有独立开关与音量，偏好保存在本机；切出页面暂停。

本仓库只用于网页评审试玩，尚未验证真实手机、微信宿主兼容或长期体验，不代表正式发行。没有账号、广告、支付或数据上报。

本地运行：python3 -m http.server 8055 --bind 127.0.0.1，然后打开 http://127.0.0.1:8055。页面采用原生ES模块，不能直接用file://打开。

版本与来源代码指纹见version.json；素材来源见NOTICE.md。
